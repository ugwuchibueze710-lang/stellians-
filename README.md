# Stellian's — Home of the 8LB Pizza

Website for Stellian's, 116 E Broad St, Central City, KY 42330 · (270) 757-1622.

Plain static site, no build step: `index.html`, `style.css`, `app.js`, `img/`.

- Hero: procedurally drawn dollar-bill wall, SVG neon sign in layered glass tubes (halo, glow and core), a physics cable from the sign's transformer to a working wall switch that turns the neon off and on with ignition flicker and a synthesized click and buzz, and the restaurant's real Freak Shakes and 8LB pizza (cut out and cleaned up) that tilt toward the pointer.
- 3D chalkboard menu with every item and price from Stellian's published menu. It flips between categories and swaps in a real photo when you hover an item.
- Freak Shake 3D coverflow, America's Best Restaurants and WBKR videos, a gallery with the printed-menu scans, reviews, and Visit Us with a live "Open now" check in Central Time.

Deploy: Render → New → Blueprint (uses `render.yaml`) or Static Site with publish directory `.`.
